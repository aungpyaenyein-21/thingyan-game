## Mood API
- `anim.mood(name|null)` sets `this.moodName`. It persists until changed. `null` returns to the character's own default (U Tin Maung `joy`, via `FACE_OV.base`). An unknown name warns and does nothing.
- `_faceNow` priority, high to low: `wet` (a hit) > `anim.face()` overlay > the pose's face (a JSON tic key) > **mood** > the character's `FACE_OV` base > the loop's own expr / mouth.
- The mood takes the slot where the `ov.base` branch sits today. The `ov.base` check also fires for the mood's name. The mood applies for any loop (idle, walk, sit), not only when the loop shows `ok`. A mood of `ok` is the same as `null` for everyone but U Tin Maung.
- The blink-cut already works on the `name` change. A mood change or an overlay ending shuts the eyes for .06 s, so the return to `sad` is not a snap.
- The talker's mouth flap still replaces only the mouth part. A `sad` face keeps its `line` mouth only while silent, so the flap does not turn it into a smile. Open question below.
- `FACE.sad` = eyes `half`, brows `out`, mouth `line`, extra null.
