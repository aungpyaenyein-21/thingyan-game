## Service worker
The old worker only intercepts paths in its `CORE` list, so an old client fetches `/` and `index.html` from the network and gets the new redirect page. The new worker caches `index.html` (cache-first) so `index.html` works offline; a bare `/` is not matched by the worker (its key is the directory path) and still goes to the network. The PWA `start_url` is `./yangon.html`, so installed apps are unaffected.
