## Steps

1. **`WEAPONS` table** — `{ pump: { range: 6, cost: .1/s, grit: .15/s, … }, balloon: { … }, bucket: { … } }` (spec A) · `k.weapon` · R to switch (keyboard + HUD) · pump becomes a held stream (not one shot) · balloon = `lob` anim + arc + ballistic + ring hit where it lands · bucket = `splash` anim + 90° cone + knockback
2. **water = ammo** — HUD bar (≤ 20% red + weak stream + drips) · refill 1.5 s (bucket filling animation · `glug`) · a hit while filling breaks it
3. **hit feel** — 40 ms hit-stop (war.js's existing `stop`, tuned in ms — world.js untouched) · .15 s shake (iso: war.js `shake`; after orbit, T2's `orbit.shake`) · squash `sy .85` · `drop` emote · recoil · Vibration 30 ms
4. **`fx.js`** — three.quarks **0.16.0** from the CDN (peer `three >= 0.165`; 0.17.x needs `>= 0.182`) · four effects as JSON · DecalGeometry pool · wet-map (the war ground material sampling the wet RT via `onBeforeCompile` — war.js's own ground only, world.js untouched)
5. **`rules.js`** — the five rules · spraying an OUT kid costs the sprayer −.3 + "ဟဲ့!" · no spraying in the mandat zone · grown-ups / monks / anyone seated · silent fights (no bubbles, emotes only) — war.js `say()` goes through rules
6. **Yuka AI (`ai.js`)** — CDN `yuka@0.7.8` (`build/yuka.module.js`) · grid A* (war.js `walkable`) → path → `FollowPath` + `ObstacleAvoidance` (drums/walls as Yuka obstacles) + `Separation` · states `advance / hold / flank / retreat / refill / supply` · roles: Thura ambush · Nga Zwe advance · May Thu lobs from the back · Cho Cho hides behind · war.js `teams/brain/engage` replaced by `ai.update(dt)`
7. **carry + `?tune`** — `carry.hit(k)` in `hit()` · OUT ⇒ the item drops · lil-gui `?tune` (hit-stop ms · shake · weapon numbers · particle counts) + JSON copy · `PositionalAudio` (pump/balloon/bucket/bell on the kids)
8. **checks** — Playwright: the three weapons (shots/clips) · water empty/refill · the five C items · AI 5v5 three rounds on `?auto` (note any snags on drums) · console errors 0 · once T2 merges: `war.html` → `camera:'orbit'` + reticle while turning
