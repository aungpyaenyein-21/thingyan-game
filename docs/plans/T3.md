## အဆင့်

1. **`WEAPONS` table** — `{ pump: { range: 6, cost: .1/s, grit: .15/s, … }, balloon: { … }, bucket: { … } }` (A ဇယား) · `k.weapon` · R ပြောင်း (keyboard + HUD) · ပြွတ်ကို ဖိထား-stream ပြောင်း (ပစ်ချက် တစ်ချက် မဟုတ်) · ပူဖောင်း = `lob` anim + arc ပြ + ballistic + ကျရာ ဝိုင်း hit · ပုံး = `splash` anim + ၉၀° cone + knockback
2. **ရေ = ကျည်** — HUD bar (≤ ၂၀% အနီ + stream အားနည်း + drip) · ဖြည့် ၁.၅ s (ပုံး ပြည့်လာ animation · `glug`) · ဖြည့်နေတုန်း ထိရင် ပျက်
3. **hit feel** — hit-stop ၄၀ ms (`W.dt` ကို ၀ — world.js မထိဘဲ war.js ထဲ `stop` ရှိပြီးသားကို ms ချိန်) · ယိမ်း .၁၅ s (iso: war.js `shake`၊ orbit ပြောင်းရင် `orbit.shake`) · squash `sy .85` · `drop` emote · recoil · Vibration ၃၀ ms
4. **`fx.js`** — three.quarks **0.16.0** CDN (peer `three >= 0.165`; 0.17.x က `>= 0.182` မို့ မရ) · effect ၄ ခု JSON · DecalGeometry pool · wet-map (ground material ကို `onBeforeCompile` နဲ့ wet RT sample — war.js ground ပဲ၊ world.js မထိ)
5. **`rules.js`** — ၅ ချက် · OUT ကို ပက်ရင် ပက်သူ −.3 + 「ဟဲ့!」 · မဏ္ဍပ် zone ပိတ် · လူကြီး/ဘုန်းကြီး/ထိုင်နေသူ · တိုက်ရင် အသံမထွက် (bubble မပြ၊ emote ပဲ) — war.js `say()` ကို rules နဲ့ စစ်
6. **Yuka AI (`ai.js`)** — CDN `yuka@0.7.8` (`build/yuka.module.js`) · grid A* (war.js `walkable`) → path → `FollowPath` + `ObstacleAvoidance` (ဒရမ်/နံရံ = Yuka obstacle) + `Separation` · state `advance / hold / flank / retreat / refill / supply` · role: သူရ ambush · ငဇွဲ advance · မေသူ lob · ချိုချို hide-behind · war.js `teams/brain/engage` ကို ဖြုတ်ပြီး `ai.update(dt)`
7. **carry + `?tune`** — `hit()` ထဲ `carry.hit(k)` · OUT ⇒ item ကျ · lil-gui `?tune` (hit-stop ms · ယိမ်း · လက်နက် ဂဏန်း · particle) + JSON copy · `PositionalAudio` (ပြွတ်/ပူဖောင်း/ပုံး/ဘဲလ် ကို ဇာတ်ကောင်ပေါ်)
8. **စစ်** — Playwright: လက်နက် ၃ မျိုး screenshot/clip · ရေ ကုန်/ဖြည့် · C ၅ ချက် · AI ၅v၅ ၃ ပွဲ auto (`?auto`) — ဒရမ်မှာ ငြိ/မငြိ မှတ် · console error ၀ · T2 merge ပြီးရင် `war.html` → `camera:'orbit'` + ချိန်ပစ် reticle

## မသေချာ / မေးစရာ

1. **ပြွတ် = ဖိထား stream** — အခု war.js က ဖိ → charge → လွှတ်မှ ပစ် (တစ်ချက်)။ spec ရဲ့ 「ဖိထား → ဖြောင့် stream」 အတိုင်း **ဖိထားသရွေ့ ဆက်ထွက်** ပြောင်းရမလား? (ပြောင်းရင် charge/arc UX ပျောက်) → **အကြံ: ဖိထား = stream၊ ဆွဲ = ချိန်**
2. **library အရွယ်** (CDN တိုင်းပြီး) — three.quarks 0.16.0 **~၂၀ KB** gzip · yuka 0.7.8 **~၈၅ KB** gzip — ၂ ခု ~၁၀၅ KB ရလား? (Rapier ၈၁၆ KB နဲ့ စာရင် ပေါ့)
3. **wet-map** — world.js မထိရလို့ war.html ရဲ့ ကြမ်းပြင် mesh ကိုပဲ (`war.js` ဆောက်တဲ့ PlaneGeometry) shader ချိတ်။ ရပ်ကွက် (T5) မှာ လိုရင် world.js ကို T5/T6 က ပြင်
4. **hit-stop** — `world.js` `dt` ကို မထိဘဲ war.js ရဲ့ `stop` (ရှိပြီး) ကို ms ညှိ — orbit ကင်မရာ `shake` ကတော့ T2 ရဲ့ `orbit.shake()` (T2 merge ပြီး)
5. **Yuka + grid A*** — war.js ရဲ့ `NODES/EDGES` Dijkstra (alley map) ကို grid A* နဲ့ အစားထိုးမလား၊ ဆက်ထားမလား? → **အကြံ: grid A* ကိုယ်ပိုင် (ai.js)၊ Dijkstra ဖြုတ်**
6. **T2 မပြီးခင်** — A–D ကို iso ကင်မရာနဲ့ ဆောက်၊ `world.js` `life.js` မထိ · T2 merge ရင် `war.html` orbit + reticle ကင်မရာ လှည့်ရင်း စစ်
7. **FPS** — container မှာ GPU မရှိ (T1/T2 လို) — laptop 60 / ဖုန်း 30 ကို Fable/ဖန်တီးသူ တိုင်း
