## Numbers now → target (a kid at size .72)
`LOOPS.speed = .39 · A · f · 2π · .92`; a kid multiplies it by `.72 × .8 × gait`.

| | now (gait 1.15) | target | how |
|---|---|---|---|
| walk | 1.14 m/s | **~1.6** | gait **1.6** (cadence ×1.39 as well, so the feet stay planted) |
| jog 🆕 | — | **~2.6** | new loop `jog` f 2.0 · A .6 → 2.49 m/s at gait 1.6 (tune A to hit 2.6) |
| run | 2.74 m/s | **~3.8** | gait 1.6 → 3.81 |

The spec says gait "~1.45"; at size .72 that gives walk 1.44 / run 3.45, short of the targets — I'll use **1.6** (a `?tune` number) unless you'd rather keep 1.45 and raise the loop amplitudes. Adults / elders unchanged (gait 1 / .7).
