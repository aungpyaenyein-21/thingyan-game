## ရှိပြီးသား — ပြန်သုံးမယ်

- **ဖျော့တာ ရှိပြီး** — `W.occluder(build)` (world.js:591) က material ကို `transparent:true` နဲ့ **ကြို clone** ထားပြီး `bake()` မှာ သီးသန့် set ထားတယ် → T1 review #1 (`needsUpdate` မသုံး) ကို ပြည့်ပြီးသား။ ပြောင်းရမှာ ray ဦးတည်ချက် (`ISOdir` ပုံသေ → ကစားသူ→ကင်မရာ) ပဲ

## အဆင့်

1. **palette.js + world.js PAL** — PAL key တွေ (cream/pink/mint/water/walk …) ကို ဖိုင်တိုင်းက သုံးနေလို့ key မပြောင်းဘဲ တန်ဖိုးကိုပဲ token ဆီ ညွှန် (`water #bfeaff → #3fd3e0`၊ `walk → sand`၊ `butter → ochre` …)။ floor → `sand`၊ hemisphere ground → `shade` · ① အင်္ကျီ `#2f8fd6` → `gang1` — grep လုပ်တော့ `world.js` / `yangon/*` (war.js မပါ) ထဲ **မတွေ့** (war.js `TEAM.A` နဲ့ cast.js ပဲ — T3/T4 ပိုင်)၊ ရပ်ကွက်ထဲ ① ကလေး ရှိရင် အဲဒီမှာ `gang1` သုံး
2. **camera.js** — camlab ရဲ့ `placeCamera` + ၄၅° snap + drag/pinch/wheel zoom (5–24) + elevation curve ကို ခွဲထုတ်၊ camlab.js က ဒါကို import ပြီး camlab ဆက်အလုပ်လုပ်ကြောင်း စစ်
3. **world.js orbit mode** — `PerspectiveCamera` · follow (`camBounds` clamp ဆက်သုံး) · ကစားသူ ရွေ့တာ `RIGHT/UP` ပုံသေ → `orbit.right()/forward()` · `zoom()` → orbit dist · `fitCam` → aspect/fov · occluder ray = ကစားသူ→ကင်မရာ · LOD `near()` (|dx|+|dz| < 26) → ကင်မရာ target ကနေ အကွာ + frustum (horizon မြင်ရလို့ ဝေးတာ ပိုပါ) · `setRoom` → ဆိုင်ထဲ = az lock 0 + room `view` → dist
4. **ထိန်းချုပ်** — ဖုန်း: ဘယ်ဘက် ခြမ်း = joystick (ရှိပြီး)၊ **ညာဘက် ခြမ်း လက် ၁ ချောင်း ဘေးတိုက် ဆွဲ = လှည့်** (🆕)၊ ၂ ချောင်း = pinch (ရှိပြီး) · keyboard Z / C · HUD ခလုတ် ဘယ်/ညာ လှည့် (`hud.js`)
5. **sky.js** — dome shader: SKY stop ၄ × (afternoon, dusk) + NIGHT ၄ ကို uniform အဖြစ် (world.js ရဲ့ `mix` ပုံစံ အတိုင်း)၊ နေ = ကမ္ဘာ ပုံသေ bearing၊ dusk အလိုက် နိမ့်/နီ၊ night မှာ ကြယ် (Points) · **paintSky** (`set.js` ရဲ့ `shwedagon` — screen 2D canvas ဆွဲ) → panorama canvas (2048×512) ပေါ် ဒီ function အတိုင်း ဆွဲပြီး horizon မှာ cylinder arc (ရွှေတိဂုံ ဘက် ~၉၀°) အဖြစ် ကပ် — **set.js ရဲ့ shwedagon မပြောင်း**၊ dusk ပြောင်းရင်ပဲ ပြန်ဆွဲ
6. **ကျွန်း အပြင်** — လှည့်ရင် BOUNDS အပြင် (ဗလာ) မြင်ရ → ground ကို အပြင်ဘက် `dust` ring + အနိမ့် အဆောက်အအုံ silhouette + fog (horizon အရောင်)။ ဘတ်စ်ကား clip plane (main.js:95) ဆက်ထား
7. **အဆောက်အအုံ ၄ ဘက်** — `flats0` `shopFlat0` `compound0` အိမ် condo ကျောင်း + downtown `shophouse` `pandal` မှာ `backs()` helper: ဘေး/နောက် ပြတင်း + ရေပိုက် + ရေတိုင်ကီ + လျှော်ထားတဲ့ အဝတ်ကြိုး (ရှေ့ထက် ရိုး) · hero ၃ ခု glTF (`art/buildings.py` → `.glb`) — preload ပြီး Lambert(flatShading) ပြောင်း၊ `W.occluder()` ထဲ static အဖြစ် ထည့် → bake + ဖျော့ ရ
8. **Shadow / perf + စစ်** — `PCFShadowMap`၊ shadow camera ±12 m၊ ဖုန်း pixel ratio ≤ 1.5 (`PHONE` → LEVELS index 2 က စ) · ၄ ထောင့် screenshot · ကောင်းကင် ၃ ပုံ (`setTime` 0 / 1 / 2) · ရက် ၁ mission ၄ ခု (ပုံးဆွဲ၊ ကြောင်ချော့၊ မီးသီး၊ ဆိုင်းဘုတ်) ကင်မရာ အသစ်နဲ့ ကစား · console error ၀ · camlab / war.html မပျက်

## မသေချာ / မေးစရာ

1. **war.html** — world.js ကို သုံးပေမဲ့ war.js က T3 ပိုင်။ → **အကြံ: `camera` option opt-in (default `'iso'`)၊ war.html က T3 မှာ `'orbit'` ပြောင်း** (war.js ၁ ကြောင်း)

3. **ဆိုင်ထဲ (rooms)** — ဝင်ရင် လှည့်ခွင့် ပိတ်၊ az 0 lock? → **အကြံ: ပိတ်** (အခန်း နံရံ ၃ ဖက်ပဲ ဆောက်ထား)
4. **minimap** — မြောက် အပေါ် ပုံသေ + ကင်မရာ မြင်ကွင်း ပုံ (cone) ထည့်၊ ဒါမှမဟုတ် map ကိုယ်တိုင် လှည့်? → **အကြံ: ပုံသေ + cone**
5. **မဏ္ဍပ် glTF** — main.js မှာ မဏ္ဍပ်က favour ပြီးတိုင်း အပိုင်း တိုးလာတဲ့ ပုံ (T5 「ကြီးလာ」 လည်း) → glTF တစ်ခုလုံး လုပ်ရင် အဲဒါ ပျက်။ → **အကြံ: မဏ္ဍပ် ဘောင် (ဝါးတိုင် + ကြမ်းပြင်) ပဲ glTF၊ တိုးလာတဲ့ အပိုင်းတွေ code အတိုင်း** ဒါမှမဟုတ် မဏ္ဍပ် အစား hero ၃ ခုမြောက် ကို တခြား ရွေး (ဥပမာ လက်ဖက်ရည်ဆိုင်)?
6. **glTF preload** — `buildSet` မတိုင်ခင် `await` (~၃၀၀ KB) → ဖွင့်ချိန် နည်းနည်း ကြာ။ ရလား?
7. **FPS** — cloud container မှာ GPU မရှိ — laptop 60fps / ဖုန်း 30fps ကို ဒီမှာ မတိုင်းနိုင် (Fable Browser pane + ဖန်တီးသူ ဖုန်း)
8. **T4 (PR #29) နဲ့ conflict** — T4 က `world.js` `yangon/wardrobe.js` `camlab.js` မှာ import version ၁ ကြောင်းစီ ပြင်ထား → **T4 merge ပြီးမှ code စ**ရင် ရှင်း
