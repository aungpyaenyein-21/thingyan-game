## ဆုံးဖြတ်ချက် — လက် IK = **analytic two-bone** (CCDIKSolver မသုံး)
- rig ရဲ့ လက်: ပခုံး `sh.rotation.set(armX, 0, armZ)` (၂ ဝင်ရိုး) → တံတောင် `elbow.rotation.x` (hinge ၁ ဝင်ရိုး) → လက်။ အလျား `ARM_UP .155 / ARM_LO .135` (chibi.js:9)
- target (body local) ကနေ cosine rule နဲ့ တံတောင် ထောင့်၊ ပြီးမှ ပခုံး X/Z — ~၃၀ ကြောင်း။ ထွက်လာတာ = pose key (`armLx armLz elbowL` …) ပဲ မို့ animator ရဲ့ blend / `_apply` / skinned mesh (chibi.js:438) အတိုင်း သွား
- CCDIKSolver က bone quaternion ကို တိုက်ရိုက် ပြင် → နောက် frame `_apply` က ပြန်ရေး၊ hinge ကန့်သတ်ချက် မရှိ (တံတောင် ဘေးကွေး) → မသုံး
- IK ကို weight (0..1) နဲ့ animation pose ပေါ် ရော — ကောက်တဲ့ .35s မှာ 0→1→0၊ `front` ကိုင်ရင် ၂ ဖက်လုံး 1၊ `head` ကိုင်ရင် တစ်ဖက် 1၊ ကမ်းပေးရင် 0→1

## အဆင့်

1. **Socket** — `chest` (spine ရှေ့ .17)၊ `head` (skull ထိပ်၊ size/hunch အလိုက်)၊ `back` (spine နောက် −.2 — ဆီပုံး နေရာ) ကို `makeChibi` ထဲ pivot အဖြစ် ထည့်၊ `handR` = `arms[1].hand`။ skin() က pivot ကို bone အဖြစ်ပဲ သုံးလို့ နောက်မှ ထည့်တဲ့ item mesh တွေ ပေါင်းမသွား
2. **IK** — `solveArm(ch, side, targetLocal) → { x, z, elbow }` + `ChibiAnimator.prototype.reach = { L: {target, w}, R: {...} }` ကို `update()` ထဲ one-shot ပြီးမှ pose ပေါ် ရော
3. **Carry pose** — `anim.carry = 'hand' | 'front' | 'head' | null` — idle/walk/run ပေါ် အပေါ်ပိုင်း layer (`_chat` လို)။ front = လက် ၂ ဖက် IK item ဘေး + `spineRx −.08` နောက်လန် · head = လက်ယာ IK item ဘေး၊ `headR*` ငြိမ်၊ `hipsRz` ယိမ်း · hand = ပုံမှန် (item က handR မှာ)။ ခြေလှမ်း `gait × (1 − .4·weight)`၊ weight > .5 ခုန် ပိတ်
4. **carry.js state** — `idle → pickup (.35s · bow ပုံ · item world→socket lerp) → carry → drop / place / give / throw`၊ ring highlight (၁ m)၊ ဘယ်ခလုတ် ပြမလဲ (`ကောက် / ချ / တင် / ပေး / ပစ်`) ကို `carrier.actions()` က ပြန်ပေး
5. **hit** — `carry.hit(person)`: head → wobble + ၃ ချက် ကျ · front → ၅ ချက် · hand → မကျ · rack → ၃ ချက်။ ကျရင် item ကို ballistic နဲ့ မြေပေါ် လွင့်ကျ (ပြန်ကောက်ရ)
6. **ရေခဲ** — `melt` timer: HUD bar + scale 1→.3 + ရေစက် sphere ၃ လုံး · ကုန်ရင် ပျောက် + 「ရေခဲ ကုန်ပြီ」 · အရိပ် ×.5 က 💭 ဖြစ်လို့ flag နဲ့ပဲ (default ပိတ်)
7. **စက်ဘီး** — `bike.js` + rack socket (item ၁ ခု **သို့** ကလေး ၁ ယောက် `coast` နဲ့ ထိုင်) · ကစားသူ 「စီး」 (×၁.၈၊ ချိုး ကျယ်၊ ဘဲလ်) · ဖိုးကျော် NPC က ရပ်ထား / လမ်းပတ်
8. **carry-lab.html + စစ်** — item ၆ ခု၊ မဏ္ဍပ် စင်၊ မေသူ (ပေး target)၊ ④ ကလေး ၂ ယောက် ပူဖောင်း ပစ် (`carry.hit` ခေါ်)၊ Playwright screenshot (size ၃ pose · head item ကျ · rack · ရေခဲ) · **cast.html tic ၂၀ ကျော် ပြန်စစ်** (အရင်/အပြီး screenshot နှိုင်း) · console error ၀

4. **socket နဲ့ ရှိပြီးသား prop** — ဖိုးကျော်/ငဇွဲ ကျောမှာ ဆီပုံး ရှိပြီး → `back` socket ကို ဆီပုံး နေရာ အတိအကျ ထား၊ item ကျော ပိုးရင် ဆီပုံး ဝှက်? spec မှာ back size မပါ (hand/front/head/bike) — socket ပဲ ဆောက်ပြီး item size `back` မထည့်ဘူး လို့ ယူထား
5. **FPS** — cloud container မှာ GPU မရှိ (T1 လို)၊ **laptop 60fps ကို ဒီမှာ မတိုင်းနိုင်** — draw call/triangle နဲ့ CPU ms ပဲ ပြမယ်၊ ဖန်တီးသူ စက်မှာ စစ်ရန်

- **ခေါင်းရွက် လက်** — chibi လက် (~.21 m) က ခေါင်းကြီးရဲ့ ထိပ်ကို မမီ → ပုံးကို မကိုင်ဘဲ **ပါးဘေးမှာ လက်မြှောက်** (spine ပေါ် point) — မြင်ရတာ 「ထောက်」 လို ဖတ်ရ
