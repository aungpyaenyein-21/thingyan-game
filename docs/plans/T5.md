## အဆင့်

1. **save + day.js skeleton** — `S.day/step/parts/night` · phase machine · title card · `range` (① polygon — ဈေး/④ ဝင်ရင် အမေ့အသံ 「`{နာမည်}`!」 ပြန်ပို့ = player ကို နောက်ပြန် lerp + hud.say) · debug param
2. **story.js + scene runner** — `play(id)` → hud.say lines → face (CHARACTERS §၁၄ `anim.face` ရှိရင်၊ မရှိရင် `expr/mouth`) → `then` · camera: `cam.focus/lock/release` (T2) · scene တစ်ခု ≤ ၃၀ s
3. **ဇာတ်ကောင်** — ဘွားဘွား (cast.js `bwabwa`) · အမေ (`mom0`) · ဆရာကြီး · ကိုဇော် · အန်တီစိန် (ရှိ) · ကလေး ၅ ယောက် (hero ngazwe phoekyaw maythu chocho — cast.js `makeCast` ပုံစံ, world.js `bean` အစား) · ငွေဖလား = carry `bowl`
4. **၁-၁ / ၁-၂** — အိမ်ထဲ နိုး (rooms.js မှာ **အိမ်ထဲ အခန်း အသစ်** — မေးခွန်း ၁) · ဘွားဘွား ဖလား ပွတ် · လမ်းလျှောက်/ပြေး/ခုန် သင် · ဂိုဏ်း စု (ငဇွဲ → ဖိုးကျော် စက်ဘီး → မေသူ → ချိုချို) · လက်နက် ၃ မျိုး သင် (T3 `rules.js`/လက်နက် ရှိရင်၊ မရှိရင် ရိုးရိုး splash) · HUD ရည်မှန်းချက် ①
5. **M1 ပိတ်စ (၁-၃)** — pulley.js + ပုံး ဗလာ ဆို မဆင်း → အောက်ကနေ ပုံးထဲ ရေ ပက်ထည့် (ပြွတ် ချိန် — hit test = ပုံး ပတ်လည် .၃ m) → လေးလာ → ဆင်း · ငဇွဲ ပက်၊ `{နာမည်}` ခံ
6. **M2 အသံချဲ့စက် (၁-၄)** — ကြောင် မပက်ရ (rules ပုံစံ — ပက်မိရင် 「ဟဲ့」 + ကြောင် ပြေး) · သွပ်မိုး target ပက် → အသံ → ကြောင် ခုန် → ချိုချို 「ငါးခြောက်」 · စက် ၂ ယောက် မ (carry `front` ×၂ — T4 `give` မဟုတ်၊ ၂ ယောက် ကိုင် pose အသစ် မလုပ်ဘဲ ဖိုးကျော် + `{နာမည်}` ဘေးချင်းကပ် လမ်းလျှောက်)
7. **M3 မီးကြိုး (၁-၅)** — bulbs.js + ကလေးတွေ ဘေးမှာ ပက်နေ (ရေစက် bulbs overlay ထဲ ထိရင် ပြန်စ) · `{နာမည်}` ပုံးနဲ့ ကာ (carry `front` — ကာထားရင် ရေစက် ပိတ်)
8. **၁-၆ / ၁-၇ / ၁-၈** — ၅ နာရီ (`setTime(.6)`) · `mandat.add ×4` · ဆရာကြီး 「ဟွန်း… မဆိုးဘူး」 · ဘွားဘွား ဖလား တင် · **ပစ် mini**: အားဖြည့် bar → `bigthrow` → ဘယ်လိုပဲ ပစ်ပစ် ဖလား လက်က ချော် (script arc — ④ ခြံစည်းရိုး ကျော်) + 「ဟာ」 + 「ဒင်း」 · ကင်မရာ `focus(bowl)` → `focus(fence)` → `release` · ည: ဘွားဘွား 「ဖလား ရှိတယ်နော်」 → 「ရှိတယ်」/「…」 → 「…」 ဆို နားရွက် နီ · အိပ် → 「ရက် ၂ — မကြာခင်」

**စစ်** — Playwright: new game → ၁-၈ အထိ auto (scene တိုင်း screenshot) · ပစ် ၃ ကြိမ် (အား ၀ / ½ / ၁) ⇒ ဖလား ④ ဘက် · ည ရွေးစရာ ၂ ခု · ရက်လယ် reload → ပြန်ဆက် · ဖုန်း 375 · console error ၀ · ကစားချိန် ၁၂–၁၅ မိနစ် (ဖန်တီးသူ)
