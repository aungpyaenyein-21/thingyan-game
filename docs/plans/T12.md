## §3 Near-lens fade, option A (`world.js`)
- `W.furniture(material)` marks it (`userData.near`) and adds `onBeforeCompile`: `if (smoothstep(uNearIn, uNearOut, length(vViewPosition)) < bayer4x4(gl_FragCoord.xy)) discard;` — dithered, opaque pass, no sorting. Shared uniforms `uNearIn 1.5` / `uNearOut 3` (`W.near`; `?tune` folder 「ကင်မရာ အနီး」, CAMERA.md §5). `W.nearM(colour)` = a cached flat furniture material (never the `M()` cache, so a wall the same colour as a sign doesn't fade).
- **bake() (review fix 1): option (a), own family.** `plain(mt)` is true for a furniture material too, so it would have merged into its square's shared vertex-colour material and lost the hook. Now `near` is part of the vertex-colour family and key: furniture merges among itself, per 8-unit square, into a vc material that carries the hook (keeps the culling). Textured furniture (signs, awnings) isn't plain → merged by its own material, hook intact. `occluder()` / `hero()` clone materials and a clone drops `onBeforeCompile` → the hook is put back on the clone (the shop-house awnings are built inside an occluder).
- Furniture: poles + cross-arms, the transformer, cables (`cableM`, `sag()`), lamp arms + boxes (**not** `L.lamp.bulb` — MeshBasic, no `vViewPosition` — nor the additive glow), free-standing signs (the lot's 「ကလေးမဏ္ဍပ် ဆောက်မည်」 + posts, the market-street sign + poles, the bus-stop route sign + post), awnings (shop-houses, the tea-shop terrace + its poles, the betel stall's sunshade + posts), Thingyan bunting (flags + string + the bamboo pole), padauk canopies + trunks (+ the school padauk's flowers). Shop-front boards sit on walls: no fade (Q2). Padauk trunks fade (Q3).
- `discard` is the colour pass only: a faded pole still casts its shadow (the shadow pass uses its own depth material) — accepted, noted in CAMERA.md §5.
- Houses keep the occluder fade; nothing else changes (not B / C / D).
