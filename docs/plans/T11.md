## How
1. **Trigger** (checked every .5 s in `teams()`; all in `?tune` `RALLY`): home side = `HOME` (`?mode=home` → ①, `?mode=away` → ④, so it works against you)
   - `homeLeft ≤ 2 && awayLeft ≥ 4` · or `OUTS[home] − OUTS[away] ≥ 3` · or `clock ≤ 45 && OUTS[home] > OUTS[away]`
   - at most `perRound 1`, never before `minRoundT 30` s into the round, never once `ended`; `?rally=force` fires 5 s in (testing)
2. **The call** (~1.5 s): a grown-up's shout as a cue bubble over the home side's back edge 「ဟေ့ … ကူမယ် ကူမယ်!」 (adults may talk — `rules.speak` only gags kids) + the bell sound + HUD 「ရပ်ကွက်က လူကြီးတွေ ဝင်ကူပြီ!」 · `orbit.focus(entry, { dist 9, t .4 })` then `release()`; any input skips it
3. **They come out**: `RALLY.adults` (2–4) `W.bean({ age: 'adult' … })` (aunties in htamein, uncles in longyi, empty-handed). **Lot map**: there are no houses, so they walk in from behind the home water-pot stand (off the lot's back edge) to the home back line; **alley map**: out of the home side's house doors (`HOUSES`). They never cross the chalk line.
4. **The barrage** (~6–8 s): each adult throws every `every .5–.7` s (`bigthrow`, a balloon appears in the hand) at the **visitors only**, aim = a visitor kid, preferring the one with the most visitors within 2 m, ± `spread .8` m · reuses `lob`'s path (`lobPath`, `release`, `stepBalloons`, `burst`) with `own = adult`, `rally = true` · total `balloons 25–30`
   - **landing ring** shown `warn .6` s before each lands (the flight time is known at release: spawn the ring at `t − .6`), pooled
5. **Rules in `soak()`** for `o.rally`: `g = RALLY.grit (.25)`, and `canOut false` → `k.grit = max(k.grit − g, min(k.grit, .1))` (never below .1, never OUT from an adult); home kids inside a ring: no grit (a splash, "oops")
6. **Adults are immune**: kids' drops and balloons hit them (the hit test includes them, the drop dies, `anim.soak` wets them) — **no grit, no foul, no 「ဟဲ့!」, no flinch**, their schedule unchanged; the AI never targets them
7. **They go back**: a laugh / wave, walk back the way they came, removed (`W.removeChar`) when out of sight · `nextRound` clears anything left
8. **`duck` (ai.js)**: visitors while the rally is live: if inside a live ring → run out of it (the nearest point outside all rings); else → the nearest grid corner whose wall is on the home side (`grid.corners(+s)` within 6 m); shoot only if a home kid is < 3 m. Ends with the barrage → `fight()`.

## Plan review 1 — fixes (Fable, 2026-11-08) — these replace the matching parts above
1. **Throw rate from the totals.** `bigthrow` is .75 s (`ONESHOT`), the balloon leaves at t > .44 and an adult can't start a one-shot while one runs. Master tune: `RALLY = { adults: [3, 4], balloons: 28, dur: 7, … }`; per-adult interval = `adults × dur / balloons` (.75–1.0 s). `every` is dropped from `?tune`.
2. **Range: rally throws bypass `lob()` / `landing()`** (which clamp to the balloon's 9 m and would drop them on the home kids). `at = pos(visitor) + spread`, then `lobPath(hand, at)` directly (flight `t = .6 + d × .12` → ~2.4 s at 15 m), capped by `RALLY.range 16`. **"Home back line" = the kids' start line** (`back` 11.5 on the lot / 16.4 in the alleys), between the taps and the stand.
3. **The shout is a world bubble over the shouting adult** (`W.speak(sprite)`, the life.js pattern), not `rules.speak` (it has no speaker and gags everything in a round); rules.js stays untouched. The HUD line goes through `say()` → **`#msg`** (not `#rule`, which reads as a foul).
4. **Adults are not in `kids`.** A separate `rally.adults` list (kids feeds `teams / active / score / tags / enemies / rayTarget / checkEnd`). One extra loop in each hit test (`moveDrops`, `stepBalloons`): a hit → the drop dies / the balloon bursts, `c.anim.soak(.25)` + `fx.burst`, nothing else — that *is* immune, no flag. The player's auto-aim and the AI iterate `kids`, so they never target adults. **`burst()` gets a rally branch**: skip home kids (cosmetic only, see A2), **skip OUT kids entirely** (no `foul()`), and the −.25 / floor .1 rule for the rest.
5. **`duck` survives the think tick**: `fight(k)` returns `'duck'` while `G.rally()` is live and `k.team !== G.homeTeam`; the refill / rest branches above it still win (a dry kid still goes to the drum).
6. **Dodging reads the in-flight list.** `G.rally()` returns the balloons in flight `[{ at, tLand }]` from release (1.3–2.4 s ahead); `duck` steers clear of any `at` landing within 1.2 s (radius ring + .4 m). The visual ring stays at `warn .6` for the player.

**Smaller**

- **Walking**: the adults aren't Yuka vehicles — a plain lerp on `W.tick` (skipped while `W.frozen`), like life.js walkers. They start walking during the call; the barrage starts when the first arrives (≈ 1.5 + 1.2 + 7 + 1.5 ≈ 11 s).
- **Round end mid-rally**: `nextRound` (and `roundOver`) also hide the ring pool, `removeChar` the adults and reset the phase.
- Rally balloons are `face: false` (goggles don't matter); Thura's ×.8 makes his −.2 — fine, the .1 floor is the rule.
- Bump `war.js?v=` in war.html and `sw.js` if it lists war.js.
