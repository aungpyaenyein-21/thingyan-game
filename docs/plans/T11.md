## How
1. **Trigger** (checked every .5 s in `teams()`; all in `?tune` `RALLY`): home side = `HOME` (`?mode=home` → ①, `?mode=away` → ④, so it works against you)
   - `homeLeft ≤ 2 && awayLeft ≥ 4` · or `OUTS[home] − OUTS[away] ≥ 3` · or `clock ≤ 45 && OUTS[home] > OUTS[away]`
   - at most `perRound 1`, never before `minRoundT 30` s into the round, never once `ended`; `?rally=force` fires 5 s in (testing)
2. **The call** (~1.5 s): a grown-up's shout as a cue bubble over the home side's back edge 「ဟေ့ … ကူမယ် ကူမယ်!」 (adults may talk — `rules.speak` only gags kids) + the bell sound + HUD 「ရပ်ကွက်က လူကြီးတွေ ဝင်ကူပြီ!」 · `orbit.focus(entry, { dist 9, t .4 })` then `release()`; any input skips it
3. **They come out**: `RALLY.adults` (2–4) `W.bean({ age: 'adult' … })` (aunties in htamein, uncles in longyi, empty-handed). **Lot map**: there are no houses, so they walk in from behind the home water-pot stand (off the lot's back edge) to the home back line; **alley map**: out of the home side's house doors (`HOUSES`). They never cross the chalk line.
4. **The barrage** (~6–8 s): each adult throws every `every .5–.7` s (`bigthrow`, a balloon appears in the hand) at the **visitors only**, aim = a visitor kid, preferring the one with the most visitors within 2 m, ± `spread .8` m · reuses `lob`'s path (`lobPath`, `release`, `stepBalloons`, `burst`) with `own = adult`, `rally = true` · total `balloons 25–30`
   - **landing ring** shown `warn .6` s before each lands (the flight time is known at release: spawn the ring at `t − .6`), pooled
5. **Rules in `soak()`** for `o.rally`: `g = RALLY.grit (.25)`, and `canOut false` → `k.grit = max(k.grit − g, min(k.grit, .1))` (never below .1, never OUT from an adult); home kids inside a ring: no grit (a splash, "oops")
6. **Adults are immune**: kids' drops and balloons hit them (the hit test includes them, the drop dies, `anim.soak` wets them) — **no grit, no foul, no 「ဟဲ့!」, no flinch**, their schedule unchanged; the AI never targets them
7. **They go back**: a laugh / wave, walk back the way they came, removed (`W.removeChar`) when out of sight · `nextRound` clears anything left
8. **`duck` (ai.js)**: visitors while the rally is live: if inside a live ring → run out of it (the nearest point outside all rings); else → the nearest grid corner whose wall is on the home side (`grid.corners(+s)` within 6 m); shoot only if a home kid is < 3 m. Ends with the barrage → `fight()`.
