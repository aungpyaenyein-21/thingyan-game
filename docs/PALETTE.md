# သင်္ကြန်ပွဲ · အရောင် (v1 — 2026-10-31 ဖန်တီးသူ အတည်ပြု)

> **မူ: "နွေ ပူပူ ရပ်ကွက် + ရေ ပဲ အေး"** — ကမ္ဘာ တစ်ခုလုံး ပူတဲ့ pastel (ဧပြီ နေပူနဲ့ ဖျော့နေသလို)၊ **ရေ တစ်ခုတည်း** အေးတဲ့ turquoise ပြင်းပြင်း။ ရေပက်တာက ဂိမ်းရဲ့ ပင်မ မို့ screen ပေါ် အမြဲ ပေါ်လွင်ရမယ်။
> Go-Go Town! က candy saturated · ကျွန်တော်တို့က ပိုဖျော့၊ ရေပဲ candy → 「ရန်ကုန် ဧပြီ」 လို့ ချက်ချင်း ခွဲသိ။

## စည်းကမ်း ၄ ချက်

1. **ကမ္ဘာ = ဧပြီ နေပူ** — saturation နိမ့်၊ ပူတဲ့ဘက်။ အရိပ် = ခရမ်းနု (အနက် မသုံး)
2. **ရေ = အေးတဲ့ အရောင် တစ်ခုတည်း** — `water` turquoise ကို ရေ (ပူဖောင်း၊ ရေစက်၊ ရေစို အကွက်၊ ချောင်း၊ ရေစည်) ကိုပဲ ပေး။ **တခြား ဘာမှ ဒီအရောင် မသုံးရ** (UI ပါ)
3. **ပိတောက် ဝါ = ပွဲ/ပျော်** — ဒုတိယ accent: မဏ္ဍပ်၊ ပန်း၊ ဇာတ်လိုက် အင်္ကျီ မူလ၊ HUD highlight
4. **ဂိုဏ်း = indigo / brick** — ① ကို ရေနဲ့ မရောအောင် ရင့်၊ ④ ကို ပန်းနု အဆောက်အအုံနဲ့ မရောအောင် brick

## ရက်/အချိန် အလိုက်

| | မနက် | နေ့လယ် (အပူဆုံး) | ၅ နာရီ | ည |
|---|---|---|---|---|
| ကမ္ဘာ | ဖျော့ pastel | **ဖျော့ဆုံး** (saturation −၂၀%) — ရေ အပေါ်လွင်ဆုံး | ရွှေရောင် (ရှိပြီး dusk) | indigo + မီးသီး |
| ရေ | `water` | `water` | `water` — **မပြောင်း** | `water` + glow |

- ရက် ၃ (အကြတ်နေ့၊ အပူဆုံး) — ကမ္ဘာ saturation ပိုလျှော့
- ရက် ၄ (ပွဲ) — padauk ပိုများ (ပန်း၊ အလံ)
- နိဂုံး — အကုန် အဖြူ၊ အရောင်က ဆံပင်/ဆီပုံး/ဖလား ပဲ

## ပြင်ရမယ့် code (T2 မှာ)

- `world.js` — floor → `sand`၊ hemisphere ground → `shade`၊ အဆောက်အအုံ material တွေ ၅ ရောင်ထဲကပဲ
- `yangon/war.js` — `TEAM.A/B` → `gang1/gang4`၊ ရေ/ပူဖောင်း/ရေစက် → `water`/`splash`၊ ရေစို → `wet`
- `cast.js` / `chibi.js` — ① ဂိုဏ်းသား အင်္ကျီ `#2f8fd6` → `gang1`
- CHARACTERS §၁၂ အရောင် မြေပုံ → ဒီဖိုင် ညွှန်း
- Token တွေကို `palette.js` (export const PAL) တစ်ဖိုင်တည်းမှာ ထား — hex ကို ဖိုင်တိုင်းမှာ မပြန်ရေး
