# ရေ fx (T3) — ချိန်ပုံ

`fx.js` ရဲ့ ရေ effect ၄ ခု — ဂိမ်းက `fx/<နာမည်>.json` ကို ဖတ်ပြီး မရှိရင် code ထဲက ပုံကို သုံးတယ်။

| ဖိုင် | ဘာ | ပေါ်တဲ့နေရာ |
|---|---|---|
| `stream.json` | ပြွတ် တစ်ချက် (ရေ ဖြောင့်ဖြောင့်) | ပြွတ် ဖိတိုင်း |
| `burst.json` | ရေ ပေါက်ထွက် (ထိတဲ့နေရာ၊ ပူဖောင်း ပေါက်) | ထိရင် · ပူဖောင်း ကျရင် |
| `sheet.json` | ပုံး တစ်ပုံးလုံး ပက် | ပုံး ပက်ရင် |
| `drip.json` | ဆီပုံး ရေကုန်ခါနီး စက်စက် ကျ | ရေ ၂၀% အောက် |

## ချိန်ပုံ

1. `fx/make.html` ဖွင့် — ခလုတ် ၄ ခုနဲ့ effect တစ်ခုချင်း ကြည့် (`?code` = JSON မဖတ်ဘဲ code ပုံ)
2. three.quarks editor (https://quarks.art) ဖွင့် → **Import** → `fx/<နာမည်>.json`
3. အရေအတွက်၊ အမြန်၊ အရွယ်၊ အရောင်၊ သက်တမ်း ချိန် → **Export JSON** → `fx/<နာမည်>.json` အပေါ် ထပ်သိမ်း
4. `fx/make.html` ပြန်ဖွင့် ကြည့် · ဂိမ်း (`war.html`) ပြန်ဖွင့်

## သတိ

- **particle ကန့်သတ်ချက်** (Fable) — stream ၄၀၀ · burst ၃၀/ထိ · sheet ၁၂၀ · drip ၂၀ · စုစုပေါင်း ၂,၀၀၀ · ဖုန်း (LEVELS low) တစ်ဝက်။ editor မှာ `maxParticle` ကို ဒီထက် မတင်ပါနဲ့
- `fx/make.html` ရဲ့ 「JSON ×4」 = code ထဲက မူလပုံကို ပြန်ထုတ် (ချိန်ထားတာ ပျောက်ချင်ရင်)
- ရေ အရောင် = PALETTE `water #3fd3e0` / `splash #cff6fa` — ရေ ပဲ အေးတဲ့ အရောင်
